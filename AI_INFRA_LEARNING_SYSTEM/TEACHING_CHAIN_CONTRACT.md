# 每个学习板块的教学链路合同

所有 Week 3–12 的 `BLOCK_LEARNING_MAP.md` 与 `PRACTICE_LAB.md` 都使用同一合同。它不是额外作业，而是防止“知道主题、却不知道如何开始或何时算会”的导航层。

```text
为什么学（价值/边界）
  → 进入条件（已有证据）
  → 只读哪些资料（带问题）
  → 最小实现/观察（一个行为）
  → 对应练习（先预测）
  → 命令与预期断言
  → 产物与评分
  → 失败分支与回补
```

每个学习板块必须有一条 `P#` 练习；通过“运行命令 + 预期断言 + 解释反例”才允许进入下一个板块。若项目实际文件名不同，先将“目标职责”映射到真实路径并记入 Work Log，禁止机械创建平行文件。

练习答案不直接给完整实现；自检规则给出行为边界。卡住 20 分钟后，按提示缩小到最小输入，再回到测试，不直接让 AI 交付整段答案。
