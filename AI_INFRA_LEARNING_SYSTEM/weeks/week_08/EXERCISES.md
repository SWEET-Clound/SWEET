# Week 8 练习册

## E1：证据强度分类

将每个成果标为直接输出、原始数据、二手描述或缺失。二手描述不能支持 Gate 通过。

## E2：30 分钟稳定运行计划

在运行前写 workload、成功标准、中止条件、采样频率和日志位置；运行后再填实际结果。禁止先运行后倒推标准。

## E3：干净环境挑战

在新 venv 只按照 README 做：创建、安装、quality gate、fake service health。每个“文档没写但需要”的步骤都记为 defect。

## E4：反证问题

回答：哪一项证据若缺失，会推翻“我已具备工程基础”？为什么？

## E5：复盘大纲

用 7 个问题写至少 2,000 字：风险、真实回归、饱和点、trace、fake 边界、兴趣、为何进入模型实验。

## E6：Gate 决策

分别为 continue/extend/pivot 写触发条件；根据证据选择一个，不能选择“暂时不判断”。
