# 第 1 周掌握度评分

总分 100。总分至少 80 且所有硬门槛通过，才算完成。

## 硬门槛

- Python 虚拟环境可重建；
- WSL2 成功，或存在明确、可验证的外部阻塞记录；
- 测试不访问真实模型或网络；
- 至少 5 个独立行为测试通过；
- 至少 10 个失败模式；
- 一条完整 trace；
- 周报完成。

任何硬门槛缺失，不因总分高而通过。

## 评分

### A. 环境可复现性：20 分

- 5：记录 Python/Git/WSL/GPU 版本；
- 5：`.venv` 创建和验证命令正确；
- 5：依赖和忽略边界明确；
- 5：能在新终端复现。

### B. 测试知识：20 分

- 5：能解释单元/集成/E2E；
- 5：能写 assert、raises、参数化；
- 5：能正确使用 monkeypatch/mock；
- 5：能解释 mock 的局限。

### C. 当前 Agent 测试：25 分

- 5：无导入时真实模型副作用；
- 10：至少 5 个核心行为，推荐 9 个；
- 5：测试独立、命名清晰；
- 5：无 API Key、无网络也通过。

### D. 失败分析：15 分

- 5：至少 10 项且分类；
- 5：包含触发、影响、信号和测试；
- 5：优先级有理由。

### E. 执行追踪：10 分

- 5：节点/边/状态变化完整；
- 3：能指出三个观测缺口；
- 2：敏感字段边界明确。

### F. 表达与复盘：10 分

- 5：口试至少 8/10；
- 3：周报有证据而非感想；
- 2：第 2 周主问题来自失败证据。

## 等级解释

| 分数 | 等级 | 含义 |
| ---: | --- | --- |
| <60 | 未形成 | 主要是看过或跟做 |
| 60–69 | E1 | 能识别概念，不能独立完成 |
| 70–79 | E2 | 能在指导下实现，但证据不完整 |
| 80–89 | E3 | 能独立完成、测试和解释 |
| 90–100 | E3+ | 还能发现设计问题并提出可验证改进 |

本周目标是 E3，不追求形式上的满分。
