## 硬门槛

- [ ] 原有 pytest 练习可在 `.venv` 重复运行；
- [ ] 10+ 离线测试通过，不访问真实模型、网络或 Key；
- [ ] Agent 代码不存在 `eval(`；
- [ ] 缺少/空白 Key 有明确且不泄露秘密的配置错误；
- [ ] 非法算式、除零、空输入均有契约和测试；
- [ ] 5+ 路由行为有离线测试；
- [ ] 有从新终端验证离线测试的说明；
- [ ] `WORK_LOG.md` 有命令、预测和复盘证据。

## 五分钟口试

每题 2 分：定义正确 1 分，能用当前项目举例 1 分；8 分通过。

3. 为什么字符白名单加 `eval` 不等于最小权限？
4. `1 / 0`、缺少 Key、模型超时各属于什么错误，谁先行动？
