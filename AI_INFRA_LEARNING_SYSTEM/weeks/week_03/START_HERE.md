# Week 3 从这里开始

## 本周只学什么

Week 3 不学习新模型，也不重写 Agent。你学习的是把一个“所有逻辑挤在单文件”的程序，变成可以单独理解、测试和安全修改的小 package。

```text
不改行为的重构
  → 每个模块只做一件事
  → 用类型写清输入输出
  → 用测试证明行为仍正确
  → 用质量门防止下次改坏
```

## 五个文件怎么用

| 文件 | 作用 | 使用时机 |
| --- | --- | --- |
| `README.md` | 板块与具体步骤 | 开始每个板块前 |
| `RESOURCES.md` | 官方资料、阅读边界 | 查概念时 |
| `EXERCISES.md` | 练习、预期与自检 | 动手前后 |
| `WORK_LOG.md` | 你的预测/命令/输出 | 每次学习结束 |
| `RUBRIC.md` | 完成与掌握标准 | 周末 |

## 进入条件

1. Week 2 的离线测试能运行；
2. 当前工作区先执行 `git status --short`，不动不属于本周的文件；
3. 不含真实 Key 的终端运行 pytest；
4. 对 `router`、`safe_calculator`、`config` 各说一句“它的责任是什么”。

若第 4 条答不出，先回 Week 2 的知识地图，不急着拆文件。

## 每次学习固定动作

1. 阅读一个小节，写一句预测；
2. 先写/运行最小测试；
3. 只做当前小步改动；
4. 立刻运行单个测试，再运行质量门；
5. 在 `WORK_LOG.md` 记录实际结果与不理解处。

本周的结束不是“文件变多”，而是你能解释 `service → graph → tools/routing/state` 的依赖方向，并用一条命令证明质量门通过。
